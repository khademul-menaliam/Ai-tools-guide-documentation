# AI Tools Guide

A practical collection of reusable AI-assisted workflows for web design, web development, and SEO.

## Guides

| Area | Start here | Purpose |
|---|---|---|
| Web Design & Development | `01-web-design-and-dev/README.md` | Design, UI, frontend and website-development workflows |
| SEO | `02-seo/README.md` | Simple user guide for the reusable SEO Agent Skill |
| SEO Skill Details | `02-seo/seo-skill-guide.md` | Complete operating and implementation reference |

## Recommended workflow

1. Choose the area you need.
2. Open that area's `README.md`.
3. Follow the short user workflow.
4. Open the detailed guide only when you need implementation or troubleshooting details.

## SEO

The SEO Skill is designed to be reusable across customer projects.

**Start:** `02-seo/README.md`

**Detailed reference:** `02-seo/seo-skill-guide.md`

The Skill currently supports regression-tested workflows for:
- Next.js / React
- Vue / Nuxt
- Angular
- Laravel

The Skill is considered **stable / ready for use**. New changes should be driven by a real reproducible defect or a clearly required capability, not by adding more roadmap phases.
